# Hardhat migration readiness review

Prepared pilot offer. Prices below are proposals for the maintainer to approve;
there is no active checkout or paid engagement implied by this page.

## What the customer receives

A review of one Hardhat project's migration state, a prioritized finding list,
JSON and Markdown evidence reports, and one written follow-up. The initial pass
uses a preserved working copy and does not execute project code. Runtime checks
and code changes require an agreed scope and a separate working copy.

## Proposed pilot packages

| Package | Proposed price, USD | Scope |
|---|---:|---|
| Readiness review | 199 | One repository, up to 40 first-party source/config files, static report and one follow-up |
| Review and focused repair | 499 | Readiness review plus up to two agreed migration blockers, capped at four engineering hours, with a reviewable patch and regression evidence |

Prices are starting hypotheses, not verified market rates or income forecasts.
The scope must be confirmed before payment. Work outside the cap requires a new
agreement; completion time begins only after access and scope are settled.

## Intake

Provide the repository URL or redacted source summary, Hardhat and Node versions,
package manager, current failure, target outcome, and whether runtime checks are
authorized. Never provide wallet secrets, credentials, customer datasets, or a
production signing environment. Use the maintainer's existing contact channel.

## Acceptance criteria

The deliverable identifies reviewed files and the exact commit, gives a
reproducible command for every check, preserves originals, separates observed
failures from heuristic advice, and states unresolved blockers. A repair includes
the test outcome and a patch. A static PASS is not a security certification.

## Rights and scope

The software's MIT license and existing notices remain in place. The fee is for
engineering services and deliverables; it does not revoke existing open-source
rights or promise exclusivity. Smart-contract audits, deployment, transactions,
financial advice, and production operations are outside these pilot packages.
